GITHUB PAGES SAFE LINKS

Use GitHub Pages-safe relative links.

Prefer:

href=”./about.html”

href=”./courses/digital-marketing.html”

href=”../index.html”

instead of blindly using:

href=”/about.html”

href=”/courses/digital-marketing.html”

because root-relative paths can cause problems when the same project is deployed as a repository Pages site.

The code must be written so the site remains functional whether it is served from:

https://USERNAME.github.io/

or:

https://USERNAME.github.io/REPOSITORY/

when possible.

Use relative paths consistently.

Do NOT mix incompatible path styles.

⸻

GITHUB PAGES SAFE ASSET PATHS

CSS:

<link rel="stylesheet" href="./css/style.css">

JavaScript:

<script src="./js/main.js"></script>

Images and icons must use correct relative paths.

Course pages must correctly reference assets from their directory.

/courses/digital-marketing.html

use:

../css/style.css

and:

../js/main.js

NOT:

/css/style.css
